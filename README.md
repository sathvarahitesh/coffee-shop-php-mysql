# Coffee Shop - PHP & MySQL

A web-based coffee shop project developed using PHP, MySQL, HTML, CSS and JavaScript.

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Features

- User registration/login
- Product listing
- Shopping cart
- Order management
- Admin panel

## Local Setup

1. Install XAMPP
2. Copy project into `htdocs`
3. Start Apache and MySQL
4. Create database `shop_db`
5. Import `database/shop_db.sql`
6. Configure database connection
7. Open:

`http://localhost/Mywebsite/`
